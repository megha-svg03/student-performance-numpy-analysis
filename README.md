# student-performance-numpy-analysis
Student Performance Data Analysis using NumPy

A beginner-friendly data analysis project using Python and NumPy to analyze student performance based on study hours, attendance, and scores.

📊 Dataset

The dataset contains:

- Study Hours
- Attendance
- Score

The dataset is stored in "study_data.csv".

🛠️ Technologies Used

- Python
- NumPy
- Google Colab
- GitHub

🔍 NumPy Concepts Practiced

- NumPy arrays
- Indexing and slicing
- Reshaping
- "flatten()" and "ravel()"
- Statistical operations
- Axis-wise operations
- Boolean indexing
- "np.where()" and "np.select()"
- Sorting and ranking with "sort()" and "argsort()"
- Array stacking
- Vectorization
- Broadcasting
- Missing and invalid value handling
- Random number generation
- Basic linear algebra

🧹 Data Cleaning

I created a modified copy of the dataset to practice:

- Detecting missing values
- Detecting invalid values
- Finding their positions
- Replacing missing and invalid values

The original dataset was kept unchanged.

📈 Analysis

The project explores student data to find simple insights such as:

- Average study hours
- Average attendance
- Average scores
- Highest and lowest values
- Values above or below the average
- Sorting and ranking records
- Score categories
- Missing and invalid values

🎯 Project Purpose

The main purpose of this project is to understand how NumPy can be used for basic data analysis.

It helped me practice the complete process:

Load → Explore → Clean → Analyze → Filter → Sort → Understand the data

📚 Learning Outcome

Through this project, I gained practical experience working with NumPy arrays and learned how numerical data can be processed and analyzed using Python.

This project is part of my learning journey toward Data Science and AI/ML.
